\# Mon Lab Infra



Laboratoire personnel d'administration systèmes et réseaux.



\## Objectifs



Mettre en pratique l'installation, la configuration et l'administration d'une infrastructure complète.



\## Environnement



\- Windows Server 2022

\- Active Directory

\- DNS

\- DHCP

\- WDS / MDT

\- Windows 11

\- Debian

\- Nginx

\- Wiki.js

\- Gitea

\- pfSense

\- TLS / HTTPS



\## Projets



\- Infrastructure Windows

\- Infrastructure réseau

\- Linux Debian

\- pfSense

\- Intelligence artificielle

\- Scripts PowerShell / Bash / Python



\## Documentation



La documentation détaillée est réalisée dans Wiki.js.



Le dépôt contient les scripts, configurations, procédures et fichiers techniques associés au LAB.

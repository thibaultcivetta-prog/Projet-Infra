# Active Directory et GPO


## Objectif

Mettre en place un domaine Active Directory et appliquer des stratégies de groupe aux postes clients.

## Travaux réalisés

- Installation d’AD DS
- Création du domaine `TSSR.LAB`
- Création et gestion des utilisateurs / groupes
- Intégration de postes Windows 11 au domaine
- Création et application de GPO
- Tests d’application des stratégies

## GPO réalisées

- Configuration du fond d’écran
- Verrouillage / paramètres de session
- Autres stratégies de test

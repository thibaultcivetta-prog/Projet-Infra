# DHCP

## Objectif

Distribuer automatiquement les paramètres réseau aux postes du LAB.

## Travaux réalisés

- Installation du rôle DHCP
- Création de l’étendue
- Configuration de la passerelle
- Configuration du serveur DNS
- Configuration du domaine
- Options nécessaires au démarrage PXE / WDS

## Paramètres principaux

- Passerelle : `192.168.60.1`
- DNS : `192.168.60.11`
- Domaine : `TSSR.LAB`
